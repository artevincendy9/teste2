Link Maste — Host File

Upload any file. Use {link_maste} in CSV data — each row gets a unique tracking URL.

ℹ How it works
  1. Upload any file here (HTML page, PDF invoice, product image, etc.)
  2. Add {link_maste} in any column of your CSV data
  3. During processing, each email gets a unique tracking URL replacing that tag
  4. When a recipient clicks the link, their visit is recorded in History (IP, location, device, time)
  5. You can delete & re-upload files anytime — existing links will point to the new file
  6. Deleting all history also invalidates all tracking links
